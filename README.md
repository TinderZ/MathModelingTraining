# 数学建模训练题集合

这是一个数学建模竞赛训练题目的集合仓库，主要包含各种数学建模竞赛的训练或实战题目、代码和解决方案。

## 📂 项目结构

### 🏆 国赛/
全国大学生数学建模竞赛相关题目和训练材料
- **五一数模/** - 五一数学建模竞赛相关题目
- **国赛训练2/** - 全国大学生数学建模竞赛训练题目2
- **国赛训练3/** - 全国大学生数学建模竞赛训练题目3
- **2024D/** - 暑假集训1，潜艇命中率 

### 🌎 美赛/
美国大学生数学建模竞赛(MCM/ICM)相关题目和训练材料
- **2020年美赛D题 足球/** - 足球数据分析题目
- **2023 C题 wordle/** - Wordle游戏分析
- **2024年MathorCup大数据B/** - 大数据建模竞赛
- **2025D 美赛实战题/** - 2025年美赛D题实战
- **国赛2000B钢材产出及运输/** - 钢材产出及运输优化

## 🛠️ 技术栈

- **Python** - 主要编程语言
- **Jupyter Notebook** 
- **机器学习/深度学习**
